# Kairomancy: Heroes of Atlantis - test builds
An online trading card game set in Atlantis. These are early **test builds**: expect bugs and placeholder art and cards.

## Play
1. Download the newest zip from **[Releases](../../releases)** and unzip it anywhere.
2. Open Steam and log in (online play uses Steam; it shows you as playing "Spacewar" - that's normal for test builds).
3. Run `Kairomancy.exe`.
4. To play a friend: both open **Play online**; one hosts or invites, the other joins. You both need the same build.

## Report a bug or an idea
Use **[Issues](../../issues/new/choose)** (or the **Report a bug** button in the game, which fills in your version):
- **Bug**: something broke or behaved wrong.
- **Balance**: a card or strategy feels too strong or too weak.
- **Idea**: a feature or improvement.
Please search the open issues first, one problem per issue.
